Comment entrer un code de triche

  1. Termine l'histoire principale : la section Codes apparaît alors dans l'onglet Progression du menu.
  2. Remplis la condition du code si elle en a une (médailles, défis, objets à collecter). Connaître la combinaison ne suffit pas.
  3. En jeu libre, appuie sur ↑ de la croix directionnelle pour sortir le téléphone.
  4. Maintiens L1 + R1 sur PS5 ou LB + RB sur Xbox, puis entre la combinaison.
Attention : activer un code désactive la sauvegarde et les trophées ou succès jusqu'à la fin de la session. Sauvegarde avant, et relance le jeu pour retrouver une partie normale.
